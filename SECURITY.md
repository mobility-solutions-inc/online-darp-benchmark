# Security Policy

## Supported versions

Only the latest tagged release and the default branch receive security fixes
during incubation.

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/mobility-solutions-inc/online-darp-benchmark/security/advisories/new>

Include affected versions, reproduction steps, impact, and any suggested
mitigation. Please do not open a public issue before maintainers have assessed the
report. We aim to acknowledge a report within five business days.

Data-quality, benchmark leakage, privacy, and license problems that could harm
participants may also be reported privately through this channel.
